## My Goal:
Crocheters typically tend to lose count of what row and stitch they are on when they work on large projects. Using paper or basic counters to keep track can also be very inconvenient, especially when they are working on more than one project at a time. This program is meant to help crocheters keep track of rows and manage projects all in one place. 

## The MVP Scope
- Create a crochet project.
- Track and update row number.
- Save project progresss in a file.
- View and edit project notes/progress.

## My Future Plans
